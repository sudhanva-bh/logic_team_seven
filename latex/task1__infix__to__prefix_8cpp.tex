\doxysubsection{Detailed Description}
Converts an infix logical expression to prefix notation. 

This file defines a function that transforms a propositional logic expression from infix form (e.\+g., A \& B) to prefix form (e.\+g., \&AB), which is useful for parsing and evaluation in logic solvers.

Converts an infix propositional logic expression to prefix notation. 

The conversion follows these steps\+:
\begin{DoxyEnumerate}
\item Reverse the infix expression.
\item Swap the opening and closing parentheses.
\item Convert the modified infix to postfix using a stack.
\item Reverse the postfix to obtain the final prefix expression.
\end{DoxyEnumerate}

Supported operators depend on implementation of is\+Operator() and get\+Precedence().
