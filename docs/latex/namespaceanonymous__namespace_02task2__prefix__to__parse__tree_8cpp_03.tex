Recursively builds a parse tree from a prefix string. 

This is the internal recursive implementation. It reads one token from the prefix string. If the token is an operator, it recursively builds its children. If it\textquotesingle{}s an operand, it returns a leaf node.

The {\ttfamily index} is passed by reference and advanced as tokens are consumed.
