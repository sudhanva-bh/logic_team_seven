\doxysubsection{Detailed Description}
Converts an infix logical expression to prefix (Polish) notation. 

This file defines a function that transforms a propositional logic expression from its standard infix form (e.\+g., A \texorpdfstring{$\ast$}{*} B) to its equivalent prefix form (e.\+g., \texorpdfstring{$\ast$}{*}\+AB). This notation is unambiguous and ideal for parsing and evaluation in logic solvers or for building expression trees.

Converts an infix propositional logic expression to prefix notation. 

This function implements the standard algorithm for infix-\/to-\/prefix conversion by adapting the Shunting-\/yard (infix-\/to-\/postfix) algorithm.

The algorithm proceeds in four steps\+:
\begin{DoxyEnumerate}
\item {\bfseries{Reverse}} the original infix string.
\item {\bfseries{Swap}} all parentheses. \textquotesingle{}(\textquotesingle{} becomes \textquotesingle{})\textquotesingle{} and \textquotesingle{})\textquotesingle{} becomes \textquotesingle{}(\textquotesingle{}. This adapts the expression for the upcoming postfix conversion, as the reversal also reversed operator associativity.
\item {\bfseries{Convert}} the modified (reversed and swapped-\/paren) string to {\itshape postfix} notation using a stack-\/based algorithm.
\item {\bfseries{Reverse}} the resulting postfix string. This final reversal yields the correct prefix notation.
\end{DoxyEnumerate}
