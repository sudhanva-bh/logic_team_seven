\doxysubsection{Detailed Description}
Converts a logical expression parse tree into Conjunctive Normal Form (CNF). 

This file implements the multi-\/step algorithm for CNF conversion\+:
\begin{DoxyEnumerate}
\item Eliminate implications (Implication-\/\+Free).
\item Move negations inward to atoms (Negation Normal Form -\/ NNF).
\item Distribute OR operators over AND operators.
\end{DoxyEnumerate}

This process generates a {\itshape new} tree that is logically equivalent to the input tree and is in CNF.
