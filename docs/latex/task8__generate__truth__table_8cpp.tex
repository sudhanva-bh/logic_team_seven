\doxysubsection{Detailed Description}
Generates and prints a truth table for a CNF formula. 

This file provides functionality to\+:
\begin{DoxyEnumerate}
\item Find all unique atomic propositions (variables) in a formula.
\item Iterate through all \$2\texorpdfstring{$^\wedge$}{\string^}N\$ possible truth assignments for N atoms.
\item Evaluate the CNF formula for each assignment.
\item Print a formatted truth table to standard output.
\end{DoxyEnumerate}

It uses an efficient pre-\/processing step to evaluate the CNF repeatedly.
