\doxysubsection{Detailed Description}
Main runner for the Logic Team Seven project. 

This file demonstrates the full pipeline of the logic toolkit. It performs the following steps\+:
\begin{DoxyEnumerate}
\item Generates a random infix formula.
\item (Task 1) Converts the infix formula to prefix.
\item (Task 2) Builds a parse tree from the prefix string.
\item (Task 3) Converts the tree back to infix for verification.
\item (Task 4) Computes the height of the parse tree.
\item (Task 5) Evaluates the tree with a sample set of truth values.
\item (Task 6) Converts the original tree to Conjunctive Normal Form (CNF).
\item (Task 7) Checks the validity (tautology) of the resulting CNF.
\item (Task 8) Generates a full truth table for the CNF.
\end{DoxyEnumerate}

It ensures all created trees are properly deleted to prevent memory leaks.
