\doxysubsection{Detailed Description}
Defines the core \doxylink{struct_node}{Node} struct and all helper functions. 

This is the central header for the parse tree. It defines the \doxylink{struct_node}{Node} data structure and provides inline helper functions for creating, copying, destroying, and analyzing nodes and their properties.
