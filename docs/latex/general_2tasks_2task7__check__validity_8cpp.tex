\doxysubsection{Detailed Description}
Checks if a CNF formula is valid (a tautology). 

A logical formula is valid (a tautology) if it is true under all possible truth assignments. For a formula in CNF, this is true if and only if {\itshape every} clause within it is a tautology (i.\+e., every clause contains a complementary pair of literals, like {\ttfamily A} and {\ttfamily \texorpdfstring{$\sim$}{\string~}A}).
