Step 3 (Helper): Recursively distributes OR over AND.

This is the core logic for the final CNF step. It applies the distributive law:

  • (A * B) + C becomes (A + C) * (B + C)
  • A + (B * C) becomes (A + B) * (A + C)

Node * anonymous_namespace{task6_convert_to_cnf.cpp}::nnf ( Node * currentNode)

Step 2: Recursively converts an implication-free tree to Negation Normal Form (NNF).

Pushes all negation (~) operators inward so they only apply to atomic propositions (operands). Applies De Morgan's laws:

  • ~(A * B) becomes ~A + ~B
  • ~(A + B) becomes ~A * ~B Also removes double negations:
  • ~~A becomes A
