Detailed Description

Checks if a CNF formula is valid (a tautology).

A logical formula is valid (a tautology) if it is true under all possible truth assignments. For a formula in CNF, this is true if and only if every clause within it is a tautology (i.e., every clause contains a complementary pair of literals, like A and ~A).

Public interface to check if a CNF formula is valid (a tautology).

Traverses the CNF tree, breaks it into clauses, and checks if every clause is a tautology. If even one clause is not tautological, the entire formula is not valid.

Parameters
cnf_rootThe root node of the CNF expression tree.
validCountAn output parameter (passed by reference) that will be populated with the count of tautological clauses.
invalidCountAn output parameter (passed by reference) that will be populated with the count of non-tautological clauses.
Returns
true if the CNF formula is valid (all clauses are tautologies), false otherwise.
