Detailed Description

Generates and prints a truth table for a CNF formula.

This file provides functionality to:

  1. Find all unique atomic propositions (variables) in a formula.
  2. Iterate through all $2^N$ possible truth assignments for N atoms.
  3. Evaluate the CNF formula for each assignment.
  4. Print a formatted truth table to standard output.

It uses an efficient pre-processing step to evaluate the CNF repeatedly.

set< char > & atoms )

Public interface to generate and print a truth table for a CNF formula.

Orchestrates the entire process:

  1. Finds all atoms.
  2. Pre-processes the CNF tree into an efficient list of clauses.
  3. Prints the table header.
  4. Iterates from $2^N - 1$ down to 0, assigning truth values and evaluating the formula for each row.
  5. Prints each row.
